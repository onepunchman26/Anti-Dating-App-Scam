# v0.8.2 — Friends and private circles / 好友与私人群组

## English

This controlled preview extends the original AI-SlowMatch project with stable IDs,
mutual friend requests, private groups of up to eight, explicit activity rosters,
individual conditions and same-version confirmations. Friends can join an activity
without a local helper or self-discovery interview. One willing member can use their
authorized ChatGPT connection for shared analysis; private profiles/chats are never
loaded by that generator. English and Chinese remain separate, persistent interfaces.

Start with [the short guide](https://github.com/onepunchman26/Anti-Dating-App-Scam/blob/v0.8.2/WEB_COMPANION.md)
or [friends/groups instructions](https://github.com/onepunchman26/Anti-Dating-App-Scam/blob/v0.8.2/FRIENDS_GROUPS.md).
Use the attached fixed-version installer or extract the entire Windows ZIP and open
Start-SlowMatch.cmd. No developer checkout or compiler is required. Upgrading preserves
account-owned data; do not delete a vault to repair installation.

Verified: Python 2,571 passed / 11 skipped; Site 37 passed; TypeScript, compile and production
build passed. Three local synthetic browser identities completed requests, invitations,
preferences, a real OpenAI draft and individual confirmation of the same option. Source,
browser and packaged executable each completed a real synthetic OpenAI request. Actual
package passed 29 isolated install/repair/retention/interruption checks. The 150-file
package comes from clean source `e22ffd2f2152d686dea612febd8ff1a484713563`.

The original owner-private Site is saved version 10, service 0.8.2, protocol 1.0; native
authenticated read-only health and the new database structure passed. Access remains
one owner, no additional users/groups/external visitors. No real shared profile was written.

Not exercised: independent second/third accounts, fresh-account authorization and the
hosted browser-to-loopback channel. Distribution eligibility and the existing undeclared
project license remain gates. Venue links and travel limits require manual verification;
no automatic map search, booking, recording or calendar changes. Group membership edits
end existing activities; deleting/blocking closes common groups. This is a controlled
preview, not a claim of general availability or verified independent-account acceptance.

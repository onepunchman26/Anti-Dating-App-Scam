# Safety Boundaries

AI-SlowMatch is for user self-protection, not retaliation.

## The Project Must Not Support

- stalking;
- doxxing;
- hacking;
- impersonation;
- harassment;
- revenge;
- blackmail;
- fake evidence generation;
- public shaming;
- deterministic "this person is a scammer" reports;
- deterministic mental health labels;
- social-credit-style dating scores;
- hidden scraping;
- uploading other people's private data without consent.

## The Project May Support

- user self-protection;
- risk-signal explanation;
- slowing down relationship escalation;
- safe identity verification education;
- refusal to send money;
- local journaling;
- privacy-preserving report generation;
- schema validation;
- signed report integrity checks.

## Required Language Norms

Use:

- "risk signal detected";
- "insufficient information";
- "consider slowing down";
- "do not send money";
- "verify identity through safe, consent-based methods";
- "this is not a legal, criminal, or psychological judgment."

Do not use:

- "this person is definitely a scammer";
- "this person is evil";
- "this person has a personality disorder";
- "this user is safe forever";
- "AI verified true love."

## Retaliation Boundary

If a user asks for spying, hacking, doxxing, impersonation, harassment, revenge, blackmail, public shaming, or entrapment, the system should refuse and redirect to safe options such as platform reporting, legal/professional support, emergency help, and preserving evidence without fabrication.

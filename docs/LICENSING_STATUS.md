## English

As checked on October 18, 2026, this repository has no root project `LICENSE` or `COPYING`
file declaring a license for AI-SlowMatch's original code. **No project-wide license has
been selected in this migration.** This note does not grant a new license. Calling the
whole application MIT, Apache-2.0 or fully open source would be inaccurate.

A public GitHub repository is not itself a general reuse license. GitHub distinguishes
the platform's permission to view/fork a public repository from broader permissions
to use, modify and redistribute software. Check the actual applicable terms before reuse.
[GitHub's licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).

Third-party components keep their own licenses and notices. The
[credit register](https://github.com/onepunchman26/Anti-Dating-App-Scam/blob/main/docs/39_open_source_credits.md), plugin `CREDITS.md` and packaged dependency
notices identify actual included material separately from design references. An MIT starter
file does not make the entire application MIT; citing another project does not mean its
code is included. The separately installed ChatGPT/Codex client and hosted services also
have their own terms. Preserve all existing notices in source and release artifacts.

These are options for a later owner decision, **not active terms**:

| Option | Practical effect and work required |
|---|---|
| MIT for original project code | Broad permission to use, modify and distribute, including commercially, subject to retaining the copyright and permission notice. Short license text; does not require derivative work to adopt the same license. Verify ownership and dependency compatibility before adoption. [OSI MIT text](https://opensource.org/license/mit). |
| Apache-2.0 for original project code | Permissive copyright terms with an express contributor patent grant and its termination conditions. Redistribution carries license, relevant notices and change-marking duties; it does not grant general trademark rights. Verify compatibility and prepare applicable LICENSE/NOTICE material. [Apache-2.0 text](https://www.apache.org/licenses/LICENSE-2.0). |
| Defer an open-source license; define a limited preview permission separately | The owner can first decide which evaluation, copying, modification and redistribution permissions to offer. No such custom permission is created here; do not advertise an unspecified preview permission as an OSI-approved license. The scope would need explicit owner-authored or reviewed terms. |

Before implementing a choice, establish rights to the original contributions, identify the
files covered, preserve third-party terms, and align the root license, package notices,
repository metadata and release description. Obtain qualified legal advice if ownership,
commercial restrictions or compatibility is uncertain. No name, grant, license header or
repository license metadata was invented or changed by this document.

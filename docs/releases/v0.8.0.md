your own sign-in. The one maintained Site is still owner-private; downloading this release
does not grant another account access. Native fresh-chat and independent-account acceptance
remain unverified. Text/WAV import and transcript correction are supported; automatic
transcription and microphone recording are not bundled.

`a056985781fda503fa2e143db35e1e3d349c23f9` (the release tag). The bootstrap is a separately
pinned release asset generated after the archive hash was known; its maintained source and
delivery receipts are on the repository's main branch. Its own checksum is in `SHA256SUMS.txt`.
No application code is rebuilt during normal installation.

Published-download verification passed on the current Windows desktop: the downloaded
bootstrap installed, checked and registered the plugin, then repeated using its verified cache.

calls, including interruption/retry, repair and retained synthetic data. This used permitted
PowerShell 7.6.5; PowerShell 5.1 was policy-blocked without bypass. It is not independent-account
or clean-device acceptance. Other 20 installed plugins remained unchanged.

After the platform exposed the installed tools, the current existing Codex desktop conversation
read the installed setup Skill, completed authenticated native health and both mode-summary
reads, and used the installed launcher for a bound synthetic local probe. No private profile
was imported or published. Fresh ChatGPT-session and independent-account acceptance remain open.

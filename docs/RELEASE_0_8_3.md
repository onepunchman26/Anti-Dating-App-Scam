# v0.8.3 — Relationship-first interviews / 关系优先访谈

## English

This controlled preview adds short relationship and friendship interviews to the existing
web companion and native Skill. The opening and all clarifications count toward a maximum
of eight initial questions. View a private draft, pause, skip, mark uncertainty or no experience,
and correct individual statements. Explicitly selected previous drafts retain corrections
and skipped topics. Optional later exploration covers mind, body, meaning and work.

Draft statements carry their source quote. Manual corrections are protected from later AI
overwrites. Saving a confirmed private profile and publishing a separate shared summary
remain separate actions. No HUMAN 3.0 level, personality diagnosis or honesty score is used
for matching. The original adaptation draws on general interview ideas with source and
license distinctions in the credits; no external HUMAN Skill or full prompt is bundled.

Start with [the installation guide](https://github.com/onepunchman26/Anti-Dating-App-Scam/blob/v0.8.3/WEB_COMPANION.md)
and [interview guide](https://github.com/onepunchman26/Anti-Dating-App-Scam/blob/v0.8.3/RELATIONSHIP_INTERVIEW.md).
Use the attached fixed-version installer or extract the whole Windows archive and run
Start-SlowMatch.cmd. Setup makes no model calls. The package contains 152 manifested files
from clean source `b880c8d0399fbfaeee9c5560e5ea60e25a280740`; later Site-only connection
timeouts and installer hash pins do not change that payload.

Verified: full Python 2,583 passed / 11 skipped before the final optional-follow-up refinement;
final interview/companion 25 passed; bootstrap 41 passed / 1 skipped; Site regression 37 passed
plus three final connection-timeout tests. TypeScript, compile, changed-Python lint, Skill
validation and production build passed. The actual EXE passed 29 install/repair/retention
checks. Three real synthetic local-browser AI requests and one final packaged EXE friendship
request completed. Restart retained the draft and confirmed correction, with private profile
revision still zero. Language changes retained draft edits and consent.

Still unverified: independent second/third-account installation and use, fresh-account plan
authorization, and hosted HTTPS-to-loopback browser acceptance. The current IAB connection
attempt waited without a response; a bounded timeout and retry recovery were added, without
relaxing origin or pairing checks. Programmatic exact-origin EXE success is narrower evidence.
The Site remains owner-private. General hybrid distribution eligibility, the existing
undeclared project license and the unavailable new attachment body remain documented gates.
This release does not claim general availability, native refreshed-chat invocation, automatic
map lookup or recording/transcription support.

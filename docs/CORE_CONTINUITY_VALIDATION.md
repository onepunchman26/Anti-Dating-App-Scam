### Implemented and connected

- Existing core conversation policy and provider handle dedicated relationship support,
  meeting preparation, user-initiated immediate help and life direction. These routes do
  not require another initial interview. Dating/friendship interviewing remains separate.
- A bounded reflection request uses only the selected conversation, up to 20 messages /
  20,000 characters. It excludes other sessions, profiles and files. Strict JSON, schema,
  exact user-source quotations and revision checks run before returning an unsaved draft.
- Existing `RelationshipSupportService` owns reviewed saves, corrections, metadata history
  and body deletion. New records need explicit review; changed source sessions and stale
  corrections are rejected. AI generation cannot silently overwrite a saved reflection.
- Reusing reviewed notes creates a new message draft with cloud consent cleared. No
  automatic message, profile update, publication, recording or peer contact occurs.
- In-flight work is guarded against profile/session changes and stop/account changes.
  Site storage and matching contracts are unchanged; no private reflection endpoint was
  added to the remote service. No new dependency or external prompt was copied.

validated assessment. Saved-record reads and corrections make no model call.

### 已实现与已连接

- 复用原沟通策略和模型接入，新增关系支持、见面准备、本人主动即时求助和人生方向主题。
  这些入口不强制重新访谈，恋爱／朋友的初访流程仍各自独立。
- 复盘只处理选中会话最近最多20条／20,000字符，不加载其他会话、私人档案或文件。
  返回未保存草稿前校验严格JSON、结构、本人原话来源及会话版本。
- 复用原 `RelationshipSupportService` 保存、纠正、记录版本操作及删除正文。新记录必须明确审阅；
  来源会话变化或旧版本纠正会被拒绝。AI生成不会悄悄覆盖已保存复盘。
- 带入后续讨论只创建新消息草稿，并清空云端确认；不会自动发送、修改档案、发布、录音或联系对方。
- 生成期间保护档案／会话修改及停止／账号切换边界。网站存储及匹配契约不变，远程服务没有新增
  私人复盘接口。本轮没有引入新依赖或复制外部提示词。

it does not introduce a second Node runtime. Installed skills never dynamically change
the application's coaching instructions. The app's public profile is not an identity
verification service, diagnosis, personality ranking or guarantee of a safe relationship.

archives are imported. No paid API, purchases/cards, automatic emails, recruitment,
public deployment or network updater. Manual owner confirmation starts work; hourly
automation remains paused. Finish the agreed scope and return to owner review.

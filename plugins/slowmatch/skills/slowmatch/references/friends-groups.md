# Friends and private groups / 好友与私人群组

## English

Use the existing Site's **Friends & groups** page or the connected `slowmatch_social`
tool. Begin with `account_read`, `friends`, or `groups` as relevant; do not enumerate
unrelated accounts or invent ID values. Exact IDs identify an account, not trust or
romantic consent. Requests/invitations need the user's explicit direction; recipients
accept for themselves. Friendship does not require discovery participation or a score.

For a 2–8-person activity, use only the selected participants' current approved
`context`. Never load private profiles, relationship reports or conversations for a
joint output. Each participant approves their own fields, audience, expiry and AI
processing. Romance exploration is two-person and separately mutual. Missing/refused
consent or an empty intersection stops shared generation. Personal private help remains
available without peer permission.

The webpage's 0.8.2 local helper can run one explicit model request using this isolated
context, a chosen model and the initiating member's authorized allowance. Other members
need no helper or interview. Venue URLs are supplied, not automatically searched or
verified. Retain uncertainty about self-reports, routes, opening hours, costs and practical
requirements. No diagnosis, deceptive-personality score, booking or external message.

Review a draft before `propose`; the checksum is not consent. Re-read the context and
version before a write; changed membership/preferences or withdrawal invalidate the
proposal. Each member confirms the exact version and option only after checking their
own conditions. Never accept on another member's behalf. Report local synthetic tests,
real AI inference and independent authenticated acceptance separately.

## 中文版

使用原网站的“好友与群组”页面，或已连接的 `slowmatch_social` 工具。按需要从
`account_read`、`friends` 或 `groups` 开始，不枚举无关账号或编造 ID。
ID 只识别账号，不代表可信或恋爱同意。申请／邀请需要本人明确要求，接收者自行接受。
好友无需参加陌生人推荐，也无需达到匹配分数。

2–8人活动只使用选中参加者当前批准的 `context`。共同输出不得读取私人档案、关系报告
或聊天。每个人批准自己的字段、接收范围、期限及 AI 处理。恋爱探索仅限两人且须另行双向同意。
缺少／拒绝授权或没有条件交集时停止共同生成。个人私下求助不要求对方许可。

网页的0.8.2本机助手可以按明确操作，以隔离上下文、选定模型和发起成员已授权的额度运行一次
AI 请求。其他成员无需助手或访谈。场所链接由人提供，未自动检索或核实。保留关于自述、路线、
营业时间、费用及必要条件的不确定性。不作诊断、欺骗性人格评分、预订或向外发消息。

`propose` 前审阅草案，校验码不代表同意。写入前重读上下文及版本；成员／条件变化或撤回使旧方案
失效。每位成员核对自己的条件后，确认准确版本和选项，不替其他成员接受。分别报告本机合成测试、
真实 AI 推理和独立认证账号验收。

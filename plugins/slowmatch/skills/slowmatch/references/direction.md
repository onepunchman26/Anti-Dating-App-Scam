# Life direction and action / 人生方向与行动

## English

This is a new project workflow. No separately installed life-direction, goal-planning
or action-plan Skill was found in the audited installed locations. Do not call this an
imported old Skill. Grilling was reviewed for development planning; its exhaustive
interrogation is not the end-user conversation style.

Begin with the user's actual tension or decision. Distinguish their values from inherited
expectations, constraints from assumptions, and lasting direction from a short experiment.
Ask about a recent concrete choice when abstraction leaves an important uncertainty.
Never prescribe the founder's path. Link a small, reversible action to a value the user
stated. Agree what it should teach, a realistic time horizon, and when to continue, adjust
or stop. Unknown capacity/resources stay unknown. Save only approved direction/action claims
in the common private profile; external scheduling requires its own user request.

## 中文版

这是本项目新建流程。在已审计安装位置中未找到独立的人生方向、目标规划或行动计划
Skill，不得称为已导入旧 Skill。已读取 grilling 了解开发审查方法，但穷尽式盘问不作为
产品用户日常沟通风格。

从用户实际冲突或决定开始，区分本人价值观与继承期待、约束与假设、长期方向与短期
尝试；抽象回答留下重要未知时再询问具体选择。不指定创始人的人生路线。把一个小而
可逆的行动与用户明确表达的价值连接，确定想了解什么、现实时间范围及继续／调整／
停止条件。能力和资源不明时保持未知。仅把已批准方向／行动条目存入共同私人档案；
外部日程需要用户单独提出。

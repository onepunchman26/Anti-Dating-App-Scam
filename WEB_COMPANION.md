# Your local conversation / 本机私人对话

## English

Private support, preparation, immediate help, reflection and life direction now have distinct conversation routes. Generate, review, correct and delete a private reflection using the existing local store; see [private reflection](PRIVATE_REFLECTION.md).

Use the [short Codex setup prompt](SETUP_WITH_CODEX.md) for the pinned **0.8.5 Windows x64
preview**. Existing ChatGPT/Codex users skip downloading another client. Codex installs
the prebuilt release and opens the local page; ordinary users do not rebuild source.

1. Open `%LOCALAPPDATA%/AI-SlowMatch/portable/Start-SlowMatch.cmd` after installation.
   It starts or reuses the helper, opens the local page and makes no AI call.
2. Choose **Connect this local page**. Existing official authorization is reused and
   models are checked. Otherwise complete official login yourself. Confirm included-plan
   use with extra credits disabled. Authorization is not inference proof.
3. Confirm the recommended account-specific private folder, or choose another protected
   local folder. Reconnect the selected folder without scanning old vaults. No source,
   OneDrive, deployment folder or another account's vault is accepted.
4. Start with dating or friendship: one short focus per turn, at most eight initial
   questions including opening/follow-ups. Pause, skip or review a draft at any time.
   Later life exploration is optional. A completed reply proves this actual AI call.
5. Expand **Prepare my shared summary**. Supply display name, own age group, city,
   accepted ages and interests. AI proposes other broad tags from this conversation.
   Missing required intent is reported, not invented. Review every field, audience,
   discovery and 30-day expiry. Download only the separate summary, then import, review
   and publish on the Site. Private chat never goes there.
6. Discover by coarse area, age and interests; both people's published limits apply.
   Copy approved candidate summaries into **Private candidate review** locally, optionally
   including your own confirmed statements. Results stay local. On interruption, read
   the latest saved result before repeating an AI request. No diagnosis or honesty score.

Local and hosted pages reuse one component implementation. Direct hosted-to-local pairing
remains under Advanced; this environment timed out, so daily private chat opens locally
without pairing-code copying or weaker browser security. Matching/friend/group operations
remain on the maintained Site. The native plugin is an alternative. Invited friends can
participate in activities without installing AI.

Private records stay on the computer; task-authorized material is processed by OpenAI.
Publication and shared generation are separate approvals; shared generation never reads
private profiles. This preview has no automatic audio recording/transcription, contact,
booking, payment or calendar changes. Current-owner synthetic browser chat, AI draft and
candidate review passed; independent installation and B/C use remain untested. The Site
remains owner-private. See [current status](CURRENT_STATUS.md).

## 中文版

私人支持、见面准备、即时求助、复盘和人生方向现有独立对话入口。复用原有本机存储生成、审阅、纠正和删除私人复盘；详见[私人复盘](PRIVATE_REFLECTION.md)。

使用[简短Codex安装指令](SETUP_WITH_CODEX.md)安装固定 **0.8.5 Windows x64预览版**。
已有ChatGPT／Codex不需重复下载。Codex安装已构建版本并打开本机页，普通用户不重建源码。

1. 安装后打开 `%LOCALAPPDATA%/AI-SlowMatch/portable/Start-SlowMatch.cmd`。程序启动或复用
   助手并打开本机页，不调用AI。
2. 点击“连接本机页面”，复用现有官方授权并检查模型；没有则本人完成官方登录。
   确认使用套餐并关闭额外点数。授权成功不等于已完成推理。
3. 确认推荐的账号专属文件夹或选择其他受保护的本地目录。重连此前选定的位置，不扫描旧库；
   不接受源码、OneDrive、部署目录或其他账号的库。
4. 选择恋爱或交友，一轮一个短重点，首轮包括开场和追问最多八问。随时暂停、跳过或看草稿，
   后续人生探索可选。收到完整真实回复才证明此次AI请求成功。
5. 展开“准备我的共享摘要”，填写展示昵称、本人年龄、城市、接受年龄和兴趣。AI根据所选
   会话提出其余宽泛标签，必要意向不明时指出缺项，不编造答案。检查字段、可见范围、发现开关
   和30天有效期，只下载独立摘要，再到网站导入、审阅及发布。私人聊天不会传过去。
6. 网站按粗略地区、年龄和兴趣发现候选，遵守双方发布限制。只复制获准摘要到本机“私人候选
   分析”，可另选本人的已确认陈述。结果留在本机。中断后先读取保存结果，避免重复调用；
   不做诊断或诚实度评分。

本机页和托管页复用同一套组件。直连配对保留在高级入口；当前环境会超时，日常私人聊天因此
在本机打开，不复制配对码、不削弱安全限制。匹配、好友、群组仍用统一网站，原生插件是另一
入口。受邀朋友参与活动不需安装AI。

私人记录留在电脑，任务授权材料可由OpenAI处理。发布和共同分析分别批准，共同分析不读取
私人档案。本预览不自动录音、转写、联系、订位、付款或改日历。当前账号已用合成材料跑通
浏览器聊天、AI草稿和候选解释；独立账号安装及B／C仍未实测。网站仍为所有者私有，详见
[当前状态](CURRENT_STATUS.md)。

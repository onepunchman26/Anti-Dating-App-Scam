# Web companion preview / 网页本机助手预览

## English

Start at the [original project's releases](https://github.com/onepunchman26/Anti-Dating-App-Scam/releases/tag/v0.8.1).
The **0.8.1 controlled preview** adds a local web companion to the existing project.
Download the Windows ZIP for that version, extract the entire folder to a private
local application location, and open **Start-SlowMatch.cmd**. Keep its window open
while using SlowMatch. No Python, Node, compiler, API key or developer checkout is
needed in the built package. The older 0.8.0 package does not contain this feature.
Check the release's evidence and SHA256SUMS; source availability is not installation
proof. The maintained Site still admits only its authorized private audience.

1. The assistant opens a local pairing page. Open SlowMatch from that page and
   paste the temporary code into **Start with yourself**. This grants that Site
   access to this assistant for up to eight hours. Never share the code. Browser
   local-network permission may require your own click. There is no network tunnel.
2. Choose **Continue with ChatGPT** if the app's account is not already connected.
   Finish the official browser login and separately allow plan usage. Return and
   check again, then check available models and choose one. Sign-in, model discovery
   and completed inference have separate status indicators. Check Manage usage and
   disable extra credits; the app cannot enforce OpenAI's credit setting by API.
3. Confirm a private folder, or leave the path blank to reuse the saved choice or
   create the default account-specific space. The app refuses Git, OneDrive, build,
   linked and other-account locations. An occupied legacy vault requires a separate
   migration; it is never scanned or adopted automatically.
4. Start a dedicated conversation. About 10–20 minutes is a suggestion, not a quota.
   Sending explicitly authorizes the current message and up to twenty recent messages
   (bounded to 20,000 characters) plus the packaged relationship Skill to OpenAI.
   Only this dedicated conversation is used; no ChatGPT history is imported. The
   user's turn is saved before the request. Failures do not invent replies or retry.
   Pause cancels locally; an already sent request may still be processed by OpenAI.
   An optional, initially unchecked control can also include up to ten confirmed or
   corrected profile statements (4,500 characters); this reduces the conversation
   context allowance to 15,000 characters. Without that choice, private profile
   statements are not sent with the conversation.
5. Review a statement in your own words and explicitly save it to the private profile.
   Correct or remove it through the same review flow. A chat reply alone changes
   neither your confirmed profile nor your shared summary.
6. Open Shared profile, read the current version, and use **Create your shared
   summary**. Choose your own answers and city/accepted cities, preview all fields,
   then separately approve publication. Dating and friendship are independent.
   Matching checks both people's cities, conditions, visibility and expiry. This
   is city-level matching, not a GPS radius or exact-distance claim.

Closing the assistant stops local access; restart and pair again to resume saved
conversations. Disconnecting the page does not delete files. Updating/re-extracting
the program folder does not move the account-owned data. Keep private backups outside
Git, OneDrive and deployment folders. Do not delete data to repair a connection.

The native plugin remains an alternative. ChatGPT desktop is optional for the web
route. Microphone capture, transcription and GPS lookup are not connected to this
new route. Text support and manual city selection remain usable. Official plan
inference does not supply raw audio, hosted MCP tools or ChatGPT memory automatically.

**Verification limits:** independent account B is unavailable and has not been tested.
Fresh-account login/installation and the eligibility of general distribution of the
hosted-UI/local-runtime combination remain gates; successful current-owner inference
does not settle them. The repository's existing undeclared project license is
unchanged; do not call the preview an approved general-purpose open-source SIWC app.

implementation follows the retrieved complete latest conversation, with that gap
explicitly retained. See CURRENT_STATUS for the actual latest test/build/deploy results.

## 中文版

从[原项目的版本发布页](https://github.com/onepunchman26/Anti-Dating-App-Scam/releases/tag/v0.8.1)开始。
**0.8.1 受控预览版**在现有项目中增加了本机网页助手。下载对应 Windows ZIP，
将整个文件夹解压到私人本机应用位置，打开 **Start-SlowMatch.cmd**，使用期间保持窗口开启。
已构建的包不要求安装 Python、Node、编译器、API key 或开发者源码环境。
旧版 0.8.0 不包含本功能。请查看发布页实测记录与 SHA256SUMS；有源码不代表安装已验证。
统一站点仍只允许已获准的私人测试受众访问。

1. 助手打开本机配对页。从该页进入慢慢相识，将临时码粘贴到“开始了解自己”。
   这允许本站访问助手，最长八小时；请勿分享配对码。浏览器可能要求本人点击允许本机网络访问，
   不使用网络隧道。
2. 若本应用尚未连接账号，选择“使用 ChatGPT 继续”，完成官方网页登录并单独授权套餐使用。
   返回后重新检查，再检查可用模型并选择一个。账号登录、模型发现、完成真实回复分别显示状态。
   请检查用量管理并关闭额外点数，本应用无法通过 API 强制设置 OpenAI 的点数开关。
3. 确认私人文件夹，或留空以重连已选位置、创建默认的独立账号空间。
   程序拒绝 Git、OneDrive、构建目录、链接目录及其他账号的档案位置。
   已有旧档案须另行迁移，不自动扫描或接管。
4. 开始专用会话。十到二十分钟只是建议，不是完成门槛。发送操作明确授权将当前消息、
   最近最多二十条消息（合计最多两万字符）及打包的关系技能发送给 OpenAI。
   只使用本次专用会话，不导入 ChatGPT 历史。请求前先保存本人消息；失败不虚构回复、不自动重试。
   暂停会在本机取消请求，已经发出的请求仍可能被 OpenAI 处理。
   另一个默认不勾选的选项允许附带最多十条本人已确认或修正的档案陈述（最多 4,500 字符），
   此时会话上下文上限降为 15,000 字符；未选择时不发送私人档案陈述。
5. 用自己的话审阅一条理解，单独确认后存入私人档案；同一流程支持修正和移除。
   一条 AI 回复本身不会改变已确认档案，也不会发布共享摘要。
6. 进入共享资料，先读取当前版本，再使用“填写共享摘要”。自己选择答案、本人城市和愿意见面的城市，
   预览全部字段，再单独批准发布。恋爱与朋友模式互相独立。
   匹配同时检查双方城市、条件、可见性与有效期；这是城市级匹配，不声称 GPS 半径或精确距离。

关闭助手即停止本机访问；重新启动、配对后可继续保存的会话。断开页面不会删除文件。
更新或重新解压程序不会移动账号私人数据。私人备份应在 Git、OneDrive 和部署目录之外，
不要为了修复连接而删除档案。

原生插件仍可作为替代入口；网页路线不要求 ChatGPT 桌面应用。
新路线尚未接入麦克风采集、转写或 GPS 查询，文字支持与手选城市可用。
官方套餐推理不会自动提供原始音频、托管 MCP 工具或 ChatGPT 记忆。

**验收限制：**第二个独立账号不可用，尚未实测。全新账号登录、安装，以及“托管网页＋本机组件”
组合面向普通用户发行的接入资格仍待确认；当前维护者推理成功不能替代这些验收。
